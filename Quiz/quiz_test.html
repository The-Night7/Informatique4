Question 10

    i--;

✅ Corrigé détaillé

Question 1 : B

Une balise <a> avec l'attribut target="_blank" demande au navigateur d'ouvrir le lien dans un nouvel onglet. L'attribut href peut contenir une URL ou une adresse email avec mailto:.

Question 2 : C

En CSS, les balises HTML brutes comme p, div, a ou h2 peuvent être ciblées directement. Les classes utilisent un point et les identifiants utilisent un dièse.

Question 3 : D

En JavaScript, une variable déclarée mais non initialisée vaut undefined. Le type booléen s'appelle boolean, et les chaînes peuvent utiliser des guillemets simples ou doubles.

Question 4 : B

Le DOM signifie Document Object Model. C'est une interface de programmation permettant de manipuler les documents web avec JavaScript.

Question 5 : B

La propriété innerHTML permet de lire ou modifier le contenu HTML d'un élément. getElementById() retourne un seul élément et le premier enfant s'appelle firstChild.

Question 6 : C

En PHP, include() génère un avertissement et laisse le script continuer. En revanche, require() génère une erreur fatale et stoppe l'exécution.

Question 7 : C

Un formulaire envoyé avec method="POST" est récupéré côté serveur avec la superglobale $_POST. Les champs sont récupérés grâce à leur attribut name, pas leur attribut id.

Question 8 : B

La fonction ceil() arrondit à l'entier supérieur. La fonction floor() arrondit à l'entier inférieur.

Question 9 : undefined

Le tableau contient 5 éléments, donc ses index vont de 0 à 4. L'index 8 n'existe pas. JavaScript affiche donc undefined.

Question 10 : 10

La boucle commence à i = 43. À chaque tour, i diminue de 3 avec i=i-c, puis encore de 1 avec i--. Donc i diminue de 4 à chaque itération.

Les valeurs testées sont : 43, 39, 35, 31, 27, 23, 19, 15, 11, 7. Cela fait 10 itérations.
