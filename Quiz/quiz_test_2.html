Question 1 : C

Le CSS peut être intégré directement dans une page HTML grâce à la balise <style> ou à l'attribut style. Un fichier externe n'est pas obligatoire. Pour un fichier externe, on utilise <link rel="stylesheet" href="...">.

Question 2 : B

Les sélecteurs de classe commencent par un point : .div, .head, .hover. Les balises s'écrivent sans préfixe, les identifiants avec #, et les pseudo-classes avec :.

Question 3 : B

Le sélecteur [attr$="valeur"] cible un attribut qui se termine par une certaine valeur. Ainsi, div[lang$="us"] cible un élément div dont l'attribut lang se termine par us.

Question 4 : C

En CSS, les couleurs peuvent être écrites en RGB. Le rouge pur correspond à rgb(255, 0, 0). Il peut aussi s'écrire #ff0000 ou red.

Question 5 : A

La propriété border-collapse: collapse; fusionne les bordures d'un tableau. La valeur separate les garde séparées. Le curseur wait affiche un indicateur d'attente, pas une croix.

Question 6 : C

target="_self" ouvre le lien dans le même onglet ou cadre. C'est aussi le comportement par défaut d'un lien HTML.

Question 7 : C

Avec let ou var, il est possible de déclarer une variable sans l'initialiser. Sa valeur sera alors undefined. En revanche, une constante déclarée avec const doit être initialisée et ne peut pas être réassignée.

Question 8 : -10

a vaut d'abord 8. La condition if(1) est vraie, donc a devient -1. Ensuite, x vaut 1, ce qui est également évalué comme vrai, donc a devient -10.

Question 9 : undefined

Le tableau contient 5 éléments, donc les index disponibles vont de 0 à 4. L'index 8 n'existe pas. JavaScript retourne donc undefined.
